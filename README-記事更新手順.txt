カマスタHP NEWS / BLOG 更新手順

1. パソコンで article-editor-LOCAL-ONLY.html を開く。
2. 「既存の記事データを読み込む」で posts-data.js を選ぶ。
3. NEWSまたはBLOGを選択し、タイトル・本文を入力する。
4. 「記事を追加・更新」を押す。
5. 「posts-data.js をダウンロード」を押す。
6. ダウンロードした posts-data.js をサイトの同名ファイルと置き換える。
7. GitHubに変更を反映するとCloudflare Pagesで自動更新されます。

注意：article-editor-LOCAL-ONLY.html は公開サーバーにアップロードしないでください。
最初の記事は未登録です。架空のニュースは掲載していません。
現在の公式サイトやドメインは変更していません。
